Cloudflare Pages deployment
1. Upload every item in this folder to a GitHub repository.
2. In Cloudflare, open Workers & Pages, then Create application.
3. Select Pages and connect the GitHub repository.
4. Choose no framework preset and leave the build command blank.
5. Set the build output directory to . (a single period).
6. Deploy the project.

The website is a static site. Its index.html file must remain at the repository root.
